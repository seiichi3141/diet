# 週間メニュー & 買い物計画

1日の目標: **約1,450kcal / タンパク質 120–130g**。カロリーの調整はご飯の量で行い、タンパク源は減らさない。
買い物は **週2回（土曜夕方・水曜）**。メニューの週は **土曜始まり**。数値はすべて概算。

## 1日の型

| 食事       | 内容                                             |
| ---------- | ------------------------------------------------ |
| 朝         | 下記 A / B / C（曜日別メニュー参照）             |
| 昼         | メイン（肉・魚・卵）+ ご飯 + 汁物 or 副菜        |
| 夕         | メイン + 副菜 + ご飯                             |
| プロテイン | **1日2杯・水割り**（朝と夜。1杯 110kcal / P20g） |

## 調理のコツ

- **鶏むねは購入日（土曜）に150g×5に分ける**。火夕（鍋）・木夕（カレー粉焼き）の2つは[下味冷凍](recipes.md#鶏むねの下味冷凍)
- **土曜の買い物後に[まとめ作り](recipes.md#週初のまとめ作り30分)**: ゆで卵5個・ほうれん草のおひたし。水曜の買い物後にゆで卵を追加し、[にんじんをレンチン](recipes.md#にんじんのレンチンアイラップ)しておくと後半が楽
- **鶏むね・ささみは片栗粉をまぶしてから焼く**とパサつかない
- 味付けの油は1日小さじ1–2（約40–80kcal）まで

## コンビニでタンパク質を確保する（外出・遠征・時間がない日）

**選ぶ基準は「タンパク質1gあたりのkcal」**。この数字が小さいほど、減量中には有利。

| 商品                                | kcal | P   | kcal/P1g | 評価             |
| ----------------------------------- | ---- | --- | -------- | ---------------- |
| サラダチキン（プレーン）            | 110  | 23g | **4.8**  | ◎ 最良           |
| プロテイン粉（持参・水割り1杯）     | 110  | 20g | **5.5**  | ◎                |
| ザバス ミルクプロテイン 脂肪0 200ml | 100  | 15g | **6.7**  | ○ 手軽さでは一番 |
| オイコス（フレーバー付き110g）      | 92   | 10g | 9.2      | ○                |
| ゆで卵1個                           | 75   | 6g  | 12.5     | △ 補助的に       |
| 1本満足バー プロテイン              | 190  | 15g | 12.7     | △                |
| inバー プロテイン ベイクドチョコ    | 213  | 10g | **21.3** | ✗ 実質チョコ菓子 |

- **プロテインバーは避ける。** 生地やチョコの分でカロリーが膨らみ、効率が粉の2〜4倍悪い
- **ドリンクタイプ（ザバス等）が現実的な代替。** 冷蔵で売られていて、その場で飲める
- **サラダチキンが最強**だが、食事として食べるものなので間食には向かない場面もある
