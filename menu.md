# 週間メニュー & 買い物計画

1日の目標: **約1,700kcal / タンパク質 110g 以上（120g前後）**（plan.md 参照）
買い物は **週2回**（週初・週半ば）で済み、食材を使い切る設計。
数値はすべて概算。お腹の空き具合・体重の落ちペースに応じて **ご飯の量（±50–100g）で調整** する。

## 1日の型

| 食事       | 内容                                                 |
| ---------- | ---------------------------------------------------- |
| 朝         | 下記 A / B / C のローテーション                      |
| 昼         | メイン（肉・魚・卵）+ ご飯 + 汁物 or 副菜            |
| 夕         | メイン + 副菜 + ご飯                                 |
| プロテイン | **1日2杯**（朝・運動後など。1杯 = 約110kcal / P20g） |

## 調理のコツ

- **鶏むねは購入日に処理**: 150gずつ4等分し、下味（塩こうじ・ネギ塩・照り焼き）をつけて2つは冷凍。パサつき防止と日持ちの両立
- **まとめ作り（週初30分）**: ゆで卵5個・鶏ハム・ほうれん草のおひたしを作り置き
- **鶏むねをしっとり**: 片栗粉をまぶしてから焼く / レンジ蒸しにする（[Nadiaの鶏むねレシピ集](https://oceans-nadia.com/recipe_list/4081)参照）
- 味付けの油は1日小さじ1–2（約40–80kcal）まで
